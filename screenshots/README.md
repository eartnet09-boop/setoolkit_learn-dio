# Screenshots

This directory currently contains four files named `passo-1.png` through `passo-4.png`. They have not been verified as terminal-only evidence; review each image and sanitize it before embedding or sharing. Only evidence from an authorized lab, with sensitive data irreversibly removed, belongs here.

## Naming convention

```text
screenshots/
├── README.md
├── passo-1.png
├── passo-2.png
├── passo-3.png
└── passo-4.png
```

Do not treat sequential filenames as proof of the image contents or as a sequence of operational steps. Before sharing an image, remove credentials, personal information, authentication/session data, and environment identifiers. Never include real credentials or personal data.
